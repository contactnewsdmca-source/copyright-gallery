# Copyright Gallery

Trang web tĩnh gồm 5 hình ảnh đã tải lên.

## Đưa lên Internet để mọi người cùng xem

Cách dễ nhất:
1. Giải nén thư mục này.
2. Đưa toàn bộ thư mục lên một dịch vụ hosting web tĩnh như GitHub Pages, Netlify hoặc Cloudflare Pages.
3. Dùng địa chỉ website mà dịch vụ cung cấp để chia sẻ cho mọi người.

## Lưu ý bản quyền

Trang có thông báo copyright, watermark hiển thị và chặn chuột phải/kéo ảnh ở mức trình duyệt. Đây không phải biện pháp bảo vệ tuyệt đối vì người xem vẫn có thể chụp màn hình hoặc lấy tài nguyên bằng công cụ khác.
